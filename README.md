# RootinTootin

**RootinTootin** is a fast-paced top-down arcade twin-stick roguelite shooter featuring procedural dungeon crawling, dynamic 2D line-of-sight lighting with real-time shadow casting, diverse room archetypes, elemental ordnance, and modular weapon & power-up progression.

## Quick Start & Controls

1. Extract the `.zip` archive for your platform.
2. Run `RootinTootin.exe` (Windows) or `./RootinTootin` (Linux / macOS).

### Controls (Keyboard & Mouse / Gamepad)
- **Move:** `WASD` / Left Stick
- **Aim & Shoot:** Mouse & Left Click / Right Stick & `RT`
- **Dash:** `Space` / `L3` (Right-time a dash through incoming fire for a **Perfect Dash**)
- **Throw Grenade:** `G` or Middle Click / `LB`
- **Interact / Swap Gear:** `E` / `A` (Hold `F` / `X` to dismantle dropped gear for scrap)
- **Pause / Settings:** `Esc` / `Start`
